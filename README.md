📌 JobFit AI Pro
🚀 An AI-powered Resume Analyzer that evaluates job readiness, extracts skills, predicts suitable job roles, and recommends personalized learning courses with visual skill analytics.
✨ Features

📄 Upload resume (PDF)
🧠 Extracts skills automatically
📊 Calculates Job Fit Score
🎯 Predicts suitable job role
❌ Identifies missing skills
🎓 Recommends online courses
📈 Visual skill analysis chart
🌐 Easy-to-use web interface (Gradio)
🧰 Tech Stack
Python 🐍
Gradio 🎛️
PyPDF2 📄
Matplotlib 📊
🚀 How it Works
User uploads a resume (PDF)
System extracts text from resume
Skills are matched with predefined skill database
Job Fit Score is calculated
Missing skills are identified
Recommended courses are suggested
Skill distribution chart is generated
